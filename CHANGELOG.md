# Changelog

All notable changes to Nani Quick Translate will be documented in this file.

## 2026-10-05

### Added

- Initial public version of Nani Quick Translate.
- Add a Raycast command for sending selected text to Nani Translate.
- Open Nani Translate through Arc for a Little Arc workflow.
- Add a Violentmonkey userscript that inserts selected text and starts
  translation automatically.
- Add linting and build workflows for local development.
- Add project documentation and an MIT license.
